10. INDIVIDUAL TEACH-BACK
Kha: trước refactor, invariant 0..100 nằm ở 4 class. Em viết LessonValidationTest trước, sau đó extract PercentageValidator. Em biết behavior không đổi vì edge-case tests và full suite vẫn pass. Refactor cải thiện DRY và làm responsibility validation rõ hơn. E2E test chứng minh Course/Lesson polymorphism, prerequisite, Progress và certificate hoạt động cùng nhau.

Trang: Enrollment liên kết Student với Course; Progress quản lý completion state. Persistence cần vì memory state mất khi chương trình dừng. File chỉ lưu IDs; khi load phải map IDs sang Course hiện tại và validate prerequisite. EnrollmentFileStore được tách riêng để Progress không xử lý File I/O. Edge-case test phát hiện empty-course certificate bug và test pass sau khi sửa.

11. SYLLABUS MAPPING
- Polymorphism: Lesson.isComplete(...) override trong VideoLesson/TextLesson/QuizLesson; Progress gọi uniform.
- Encapsulation: Progress.completedLessons private; normal update và restore đều validate trước khi tạo state.
- Composition: Course chứa ordered List<Lesson>; Enrollment giữ Progress.
- Exceptions: IllegalArgumentException/IllegalStateException cho invalid domain operations; IOException cho persistence/file errors.
- SRP: EnrollmentFileStore xử lý File I/O, domain classes giữ domain responsibility.
- Refactoring: duplicate percentage validation → PercentageValidator.
