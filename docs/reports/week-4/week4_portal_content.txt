3. KHA – EXTENSIBILITY DEMO / OPEN-CLOSED PRINCIPLE

Kha thêm hai production classes mới:
- AssignmentLesson extends Lesson.
- AssignmentEvidence implements CompletionEvidence.

Completion rule:
Assignment hoàn thành khi submittedWordCount >= minimumWordCount.

Validation đặc thù:
- minimumWordCount <= 0 → IllegalArgumentException.
- submittedWordCount < 0 → IllegalArgumentException.
- wrong CompletionEvidence subtype → isComplete(...) trả false.
